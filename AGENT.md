# Инструкция для агента: установить Remote Claude на VPS

Ты (агент) ставишь Remote Claude на сервер человека. Делай шаги строго по порядку. Команды копируй как есть.

## Правила

1. Не придумывай своих команд и не правь файлы в `infra/`, `kit/`, `portal/`. Меняешь только `kit.conf`.
2. Если команда закончилась строкой `ШАГ НЕ ПРОШЁЛ` или `ОШИБКА`, остановись. Покажи человеку последние 30 строк вывода и спроси, что делать. Повторить ту же команду один раз можно: установщик безопасно повторяется.
3. Секреты (Client secret Google, вход в Claude) вводит **только человек** в своём терминале. Никогда не проси прислать их тебе в чат.
4. Всё, что начинается с `sudo`, запускай на сервере в папке репозитория.
5. Установка идёт 10–25 минут. Не прерывай команду, пока она печатает.

## Шаг 0. Что нужно до начала (проверь с человеком)

- VPS: Ubuntu 24.04, процессор x86_64, от 2 ГБ памяти (лучше 4 ГБ), от 15 ГБ диска. Ты подключён к нему по SSH пользователем с `sudo`.
- Подписка Claude Pro или Max у человека.
- Аккаунт Google: им человек будет входить на сайт.
- Одно из двух:
  - **свой домен** (например `claude.example.com`), у которого A-запись указывает на IP сервера, и открытые у хостинга порты 80 и 443;
  - или **аккаунт Tailscale** (бесплатный), если домена нет.

## Шаг 1. Скачать репозиторий на сервер

```
sudo apt-get update && sudo apt-get install -y git
git clone <адрес репозитория, который дал человек> remote-claude
cd remote-claude
```

Если репозиторий закрытый, `git clone` попросит вход: попроси человека дать доступ (токен или ключ развёртывания) и не печатай токен в чат.

## Шаг 2. Задать вопросы человеку

Задай человеку эти вопросы, по одному, и запиши ответы:

1. **Почта Google владельца** (только этот человек будет администратором).
2. **Почты друзей**, которым тоже можно входить (можно «никого»; потом их добавляют на странице Access).
3. **Свой домен или Tailscale?** Если домен: какое имя сайта (например `claude.example.com`)? Проверь вместе с ним, что A-запись домена уже указывает на IP сервера.
4. **В какой стране сервер?** Если в России (или другой стране, где Claude недоступен), нужен прокси WARP.
5. **Какие разделы нужны?** Предложи готовый набор:
   - **обычный** (советуем): Code Web, Console, Prompts, Skills, System instructions, Memory, Access;
   - **минимум**: Code Web, Prompts, Skills, System instructions;
   - **всё**: обычный + Computers (подключить свой компьютер и Chrome), API Agent (агент на других моделях за деньги по API), голосовой ввод (нужно 4 ГБ памяти).
6. **Ночные резервные копии** на этом же сервере: да или нет (советуем да).

## Шаг 3. Записать kit.conf

```
cp kit.conf.example kit.conf
nano kit.conf
```

Заполни по ответам (значения в двойных кавычках):

| Ответ | Что написать |
|---|---|
| почта владельца | `OWNER_EMAIL="name@gmail.com"` |
| почты друзей | `MEMBERS="a@gmail.com b@gmail.com"` или `MEMBERS=""` |
| свой домен | `SITE_MODE="domain"` и `DOMAIN="claude.example.com"` |
| Tailscale | `SITE_MODE="tailscale"` и `DOMAIN=""` |
| сервер в России | `PROXY="warp"`, иначе `PROXY="none"` |
| набор разделов | в строках `FEATURE_…` поставь `"yes"` или `"no"` по таблице в комментарии файла |
| резервные копии | `BACKUPS="yes"` или `BACKUPS="no"` |

Проверь:

```
./install.sh check-config
```

Должен напечататься список «Владелец…, Адрес…, Разделы…». Покажи его человеку и спроси «всё верно?». Если есть строка `ОШИБКА в настройках`, исправь то, что в ней названо.

## Шаг 4. Установка

```
sudo ./install.sh
```

Что будет происходить (8 шагов, у каждого заголовок `== Шаг N/8`):

- **Шаг 3 (сеть), только Tailscale:** напечатается ссылка `https://login.tailscale.com/...`. Передай её человеку: он открывает и входит в Tailscale. Команда сама продолжит.
- **Шаг 7, только Tailscale:** может появиться ссылка на включение Funnel. Передай человеку: он открывает её и нажимает Enable.
- **Шаг 7, свой домен:** получение сертификата занимает до 3 минут.

В конце выполнится проверка. Нормальный итог первой установки:

```
Итог: сервер готов, осталось сделать человеку:
  - Google: ...
  - Claude: ...
```

Если вместо этого `Итог: есть ОШИБКИ`, выполни правило 2.

## Шаг 5. Вход через Google (делает человек, ты только объясняешь)

Передай человеку эту инструкцию, подставив адрес сайта из вывода установки:

1. Откройте https://console.cloud.google.com, создайте проект (любое имя).
2. Меню **Google Auth Platform** (раньше называлось APIs & Services → OAuth consent screen): **Get started**, имя приложения любое, почта поддержки — ваша, аудитория **External**. Затем **Audience → Test users**: добавьте свою почту и почты друзей.
3. **Clients → Create client** (или APIs & Services → Credentials → Create credentials → OAuth client ID): тип **Web application**. В **Authorized redirect URIs** добавьте ровно: `https://АДРЕС-САЙТА/oauth2/callback`. Нажмите Create.
4. Скопируйте Client ID и Client secret.
5. В своём терминале SSH, в папке `remote-claude`, выполните `sudo ./install.sh google` и вставьте их (secret на экране не виден).

Пока приложение в режиме Testing, войти могут только почты из списка Test users. Новых друзей добавляйте и туда, и на страницу Access портала.

## Шаг 6. Вход в Claude (делает человек)

Попроси человека в своём SSH, в папке `remote-claude`, выполнить:

```
sudo ./install.sh claude-login
```

Он выбирает тему, вход подпиской Claude, открывает ссылку, входит, вставляет код. Когда появится строка ввода Claude, пишет `/exit`.

## Шаг 7. Финальная проверка

```
sudo ./install.sh doctor
```

Нужен итог `Итог: всё готово. Откройте https://… и войдите почтой …`. Сообщи человеку адрес сайта. Готово.

## Потом

- **Обновить** до новой версии: `cd remote-claude && git pull && sudo ./install.sh`.
- **Поменять разделы** или добавить почты: правка `kit.conf`, затем `sudo ./install.sh`. Почты удобнее менять на странице Access в самом портале.
- **Что-то не работает:** `sudo ./install.sh doctor` и показать вывод человеку. Журнал установки: `/var/log/remote-claude-install.log`.
